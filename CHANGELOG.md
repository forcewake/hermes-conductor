# Changelog

## v0.1.0 — 2026-08-25

First public release.

- 7 field-tested patterns for multi-agent kanban orchestration (`patterns/`)
- 2 installable skills: `kanban-orchestrator` (decompose / route / verify, no executing) and `kanban-worker` (evidence-only completion)
- Demo of a real 3-agent run: asciinema cast, animated SVG, and a narrated cut with step-by-step commentary (`assets/`)
- Kanban CLI cheatsheet (`examples/kanban-cheatsheet.md`)
